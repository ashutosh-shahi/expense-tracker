# 💰 Expense Tracker

A simple expense tracker built using HTML, CSS and JavaScript.

## Features

- Add expenses
- Delete expenses
- Clear all expenses
- Automatic total calculation
- Expense count tracking
- Input validation
- Dynamic DOM updates
- Local Storage support

## Technologies Used

- HTML
- CSS
- JavaScript

## Future Improvements

- Search expenses
- Filter by category
- Edit expenses
- Monthly reports
