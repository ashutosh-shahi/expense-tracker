# Expense Tracker

A full-stack Expense Tracker application built using HTML, CSS, JavaScript, Node.js, and Express.js.

The application allows users to manage expenses through a modern dashboard interface with category filtering, search functionality, dark mode support, and RESTful backend APIs.

## Features

### Frontend

* Add new expenses
* Delete expenses
* Search expenses by name
* Filter expenses by category
* Dark mode toggle
* Real-time expense count
* Real-time total expense calculation
* Responsive dashboard UI
* Local Storage support

### Backend

* REST API built using Express.js
* Create Expense (POST)
* Read Expenses (GET)
* Update Expense (PUT)
* Delete Expense (DELETE)
* JSON request and response handling
* Route parameter handling

## API Endpoints

### Get All Expenses

```http
GET /expenses
```

### Add Expense

```http
POST /expenses
```

### Update Expense

```http
PUT /expenses/:id
```

### Delete Expense

```http
DELETE /expenses/:id
```
